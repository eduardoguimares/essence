# Inefficient equilibrium

Cal Newport and Jaron Lanier both talked about how the current model traps people into using social media because everyone else is using it. The downsides of not using social media outweigh the positives of using social media because then that person would one of a few people not using it

In a more extensive explanation, there are downsides of not using social media: you are not in par with everyone else; but there are also downsides of using social media: anxiety, narrow thinking, time wasting, exposing personal data, etc.

Because of the social media's business model, social media companies are receiving money for companies and people to manipulate platform's users

The majority of people would need to collectively quit social media

> Individually speaking, one has to make a decision -> use or not use social media and how
