# Archiving in society

Societies with no archives, have no [[History]]. Preserving is a fundamental part in our progress and it will help future researchers and historians to understand us

## Digital archiving

It poses a difficult problem since digital tools use different data formats to read and present data and webpages disappear as fast as they appear, which makes it difficult to find information from more than 10 years ago[^2]

It's important to preserve the web because web content is part of our culture

### File over app philosophy

*If you want to create digital artifacts that last, they must be files you can control, in formats that are easy to retrieve and read. Use tools that give you this freedom* because tools come and go, but the plain text files *have a chance to last*[^3]

> [!a] Example
> Note-taking apps that use [[Markdown]] files like [these ones](https://www.markdownguide.org/tools/)

# Archiving in organizations

*Archiving is a crucial aspect of [[data management]], as it allows organizations to preserve important information for future reference. Archiving involves identifying and selecting data that is no longer actively used but still has long-term value and moving it to a separate storage environment. This process helps to reduce the amount of data stored on primary storage systems, which can improve system performance and reduce costs*[^4]
