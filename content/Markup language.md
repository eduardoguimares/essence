*A markup language is a text-encoding system which specifies the structure and formatting of a document and potentially the relationship between its parts. Markup can control the display of a document or enrich its content to facilitate automated processing*[^1]

It contains a set of rules that define the way text is *included in a document and how it is combined with the content of the document in a way to facilitate use by humans and computer programs*[^1]
