Deep Learning is a subset of [[Machine Learning]] based on learning and improving on its own by examining computer algorithms. It uses artificial neural networks that aim to imitate the human brain

Deep Learning models try to predict the next events
- Recurrent Neural Network - tries to predict the next word in a sentence. It takes each word as an input and considers the generated output as an input of the next word
- Seq2Seq - generates a different item sequence from an item sequence
