Deviance continuum is a very useful [[Perspective]]. It refers to a spectrum that considers both positive and negative results

![[Media/deviance continuum|700]]

The left side is refers to the negative deviance continuum and it represents negative results

The right side refers to the positive deviance continuum and it represents positive results. Positive in the sense that it *refers to that which fosters, or results in, flourishing (Fredrickson & Losada, 2005), thriving (Spreitzer, et al., 2005), optimal functioning (Keyes, 2002), capacity-building (Dutton & Glynn, 2007), or the best of the human condition*[^1]
# Deficit value system

It refers to a [[Mentality]] that focuses on not achieving negative results

# Abundance value system

In Psychology it is referred to [[Positivity]]. It refers to a [[Mentality]] that promotes reaching more than what's normal or expected

Useful mentality for achieving [[Success]]

[[Organization]]s should integrate the abundance value system to their values

[[Leadership|Leaders]] should be *building on sources of strength, resilience, and vitality, rather than simply solving problems and overcoming difficulties*[^1]

> [!a] Real world example
> Cameron describes the success example of the Rocky Flats where they used the abundance approach: *The impossible was made possible by adopting an abundance value system rather than a deficit value system*[^1]
