DNS is a database with the pairing between [[IP address|IP addresses]] and domain names like [example.com](https://example.com). While computers read the IP addresses, users can use a domain

DDNS refers to Dynamic DNS. Even if the IP address changes for some reason, the DDNS makes sure the some easy to remember domain is connected to the new public-facing domain[^1]

[^1]: *What Is Dynamic DNS (DDNS), and How Do You Set It Up?*, Jason Fitzpatrick (2023)
