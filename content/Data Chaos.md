Universal phenomenon that happens in organizations *as teams successfully drive growth (...) the diversity and magnitude of these data objects naturally expand*[^1]. API changes, privacy policies, web and app design changes, changes in tools, etc.

# Biggest causes

- Inaccurate data
- Missing data
	- Data can be lost in the transition between two systems
	- Data could not have been collected due to badly adjusted collection systems like scanners and sensors
	- Data could have been collected without enough data
- Poorly designed interfaces
	- They require more time to interpret
	- It increases the risk of errors
- Non-standardized data formats
	- It is more difficult to compare data
- Outdated data


[^1]: *What is Data Chaos? And how to solve it*, Michael Katz (2022)
