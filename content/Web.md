The Web is a network of documents on the [[Internet]]

# Evolution

## Web 1.0

This is the first state of the Web - 1996~2001

Data and content is provided by a static file system through HTML pages. CSS can be added for easier design. Users can only read data

## Web 2.0

This is the current state of the Web. It is characterized by higher levels of interaction thanks to new programmings languages like Javascript and PHP

Javascript made possible client-side interactions and PHP made possible server-side interactions. That way, users could start creating content without their own server. They would need to sign up at a platform hosted on a website

These new dynamics sparked new businesses, some based on an ad [[business model]] and others based on a subscription business model. The Web 2.0 ended up leveraging the mobile, social, analytical and cloud technology ([[SMAC model]])

## Web 3.0

The Web 3.0 is a concept for a new version of the Web. There are different ideas for what the Web could become

One of the ideas is the Semantic Web which *provides a common framework that allows data to be shared and reused across application, enterprise, and community boundaries*[^4]. The Solid project being developed by Tim Berners-Lee aims to make this possible. Each user could contain "pots" of personal data that can be used by applications. There would be universal standards for the data format saving resources for companies and each user would own their own data

Another idea is the use of [[Blockchain]] as the base for the development of new applications - Decentralized applications (Dapps). Or even the use of [[Artificial Intelligence]]

The Web 3.0 could also be the dissemination of the Internet of Things

# Web page structure

HTML (HyperText [[Markup Language]]) - the structure of a web page
CSS (Cascading Style Sheets) - the style of a web page
JavaScript - the dynamics of a web page

*You can also look at HTML, CSS, and JavaScript this way: HTML is the structure of a house, CSS is the interior and exterior decor, and JavaScript is the electricity, water system, and many other functional features that make the house livable*[^2]


[^4]: W3C (2013)
