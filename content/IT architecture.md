# Enterprise architecture

It is a plan that defines the structure and the functioning of the organization strategically and in terms of its information and IT asset processes holistically

Enterprise architecture is able to deal with the IT landscape in a way that it allows people to make improvements in a subset without messing with the rest of the landscape. It also allows people to focus on the changing aspects of the organization. It makes the landscape robust, flexible and efficient and it implements a process to keep everything organized. This reduces the IT systems complexity, improves the alignment with the organizational activity and strategy, improves organizational performance and reduces IT costs

This requires a project start architecture made by a project team that underlines how the total landscape will look when the project is complete[^2]

## Levels[^3]
![[IT architecture journey|700]]

### Application [[Data silo|Silo]] Architecture

The architecture consists of individual applications

#### Benefits

- It encourages local optimizations and innovations
- New projects are easily predictable, measurable and assessable

#### Risks

- High maintenance costs
- No integration between applications

### Standardized Technology Architecture

The architecture covers the whole organization, standardizing IT technologies
#### Benefits

- Less costs, more efficiency and more reliable
- Easier maintenance
- More data reliability and security

#### Risks

- No integration between applications because each app decides which data to use
- Organization assumes the IT architecture as a mere infrastructure sharing-point
- Conflicts between users and managers because users might try to seek more convenient solutions while managers might try to restrict technological proliferation

### Rationalized Data Architecture

The architecture expands to the point of standardizing data/information and the processes and it is now managed centrally with its core optimized
It allows for more efficient processes and it encourages innovation

### Modular Architecture

The architecture applies standards to the whole organization, with applications, data and technological components loosely connected in a way it preserves global standards without impeding local actions

It creates more opportunities for innovation and potential improvements in the strategic agility and the capacity in providing solutions. However, without data supervision and without optimization of the applications, it can 
lead to new silos
