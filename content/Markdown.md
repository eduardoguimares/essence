*Markdown is a lightweight [[Markup language]] that you can use to add formatting elements to plaintext text documents*[^1]. The formatting elements include typical characters like these `*->_`

# Why use Markdown

- Markdown can be used for everything (websites, documents, notes, books, presentations, emails and technical documentation)[^1]
- Markdown is portable and platform independent. It can be used by most applications and used in any platform[^1]
- Markdown is future proof. Tools come and go but files *have a chance to last*[^2]


[^1]: markdownguide.org
[^2]: *File over app philosophy*, kepano (2023)
