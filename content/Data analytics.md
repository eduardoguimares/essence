Data analytics is a process of data analysis that aims to produce results and feedback. Analytics helps make sense of reams of information and helps in the decision-making process by presenting information in a comprehensible way - it supports [[Business Intelligence]]

# Types of data analytics

## Descriptive data analytics

It aims to summarize historic data with the goal of extracting useful information and preparing data for additional and more sophisticated analysis

## Predictive data analytics

It aims to elaborate predictions of events and unknown phenomenons, using methods and diversified data analytics techniques

## Prescriptive data analytics

It aims to find or suggest the best course of action in the presence of various alternatives and known parameters

# Big data

Big data refers to the data sets too large or too complex to be analysed with traditional data analytics tools

|              | Big data                                                                                                                                     | Traditional data                                                                                                                                                                |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Data sources | Data generated outside the enterprise from non-traditional sources like social media, sensor data, log data, device data, video images, etc. | Traditional enterprise data like enterprise resource planning transactional data, [[Customer Relationship Management\|CRM]] systems, [[Web]] transactions, financial data, etc. |
| Volume       | Terabytes - Zettabytes                                                                                                                       | Gigabytes - Terabytes                                                                                                                                                           |
| Velocity     | Often real time                                                                                                                              | Batch or near real-time                                                                                                                                                         |
| Variety      | Could be structured, unstructured or multi-structured                                                                                        | Could be structured or unstructured                                                                                                                                             |
| Value        | Complex, advanced, predictive business analysis and insights                                                                                 | Business intelligence, analysis and reporting                                                                                                                                   |
