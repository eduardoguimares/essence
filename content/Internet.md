*The Internet is the global system of interconnected computer networks that uses the Internet protocol suite to communicate between networks and devices. It is a network of networks that consists of private, public, academic, business, and government networks of local to global scope, linked by a broad array of electronic, wireless, and optical networking technologies*[^1]

The Internet is made by a large number of independently operated networks, fully distributed, without a central control. The independent networks, driven by business decisions, are motivated the assure end-to-end connectivity between any device[^2]

# How computer systems communicate

Data sent through layers determined by a protocol. The protocol defines a set of rules that allow for a computer from a [[network]] to communicate with any other computer from another network. The data is broken into small packets and when received it gets put back together by the receiving computer[^5]

The protocols are included in the Internet Protocol suite, *a framework for organizing the set of communication protocols used in the Internet and similar computer networks according to functional criteria*[^1]

## OSI model[^4]

It contains 7 layers
- Physical layer
- Data link layer
- Network layer
	- [[IP address]]
- Transport layer
	- Transmission Control Protocol
- Session layer
- Presentation layer
- Application layer

## TCP/IP model

- Application layer
	- [[DNS]]
	- [[HTTP]]
- Transport layer
- Internet layer
- Network access layer

# History

It is a result of the project ARPANET (Advanced Research Projects Agency NETwork). Vint Cerf and Paul Baran tried to create a communication system that could survive a nuclear attack. The idea was a distributed packet-switched network where there were *breaking messages up into blocks* transmitted very fast in any possible direction. They did a nationwide experiment and it worked![^2]
