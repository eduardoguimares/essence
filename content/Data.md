- Alphanumeric
- Audio
- Image
- Video
- Metadata - data about other data

# Concepts related to data

- Database - collection of sets of data stored systematically
- Data warehouse - big set of data that integrates data from various banks of data and [[Data silo]]s and that organizes them for complex analysis, knowledge discovery and decision-making support
	- Subject-oriented
	- Non-volatile - once the data is stored, it can't be changed
	- Time variant - it stores data for a period of time and it contains historical data
	- Summarized - the data is processed, segmented and stored
	- Integrated with various analytics and reporting tools and common conventions for data processes are defined
- Data mart - data warehouse in a small scale that supports one unique role or department
	- Companies that can not invest in databases can start with data marts

# Data life cycle

![[Data life cycle.svg|700]]

- Data from various sources is stored in a database
- It can be sold in a Data Mart or directly analysed through [[Online analytical processing]], queries, Executive Information Systems or Decision Support Systems
	- It can also be used for data mining
- Then, it can be applied in business for Supply Chain Management, Customer Relationship Management, E-commerce or [[Strategy]]
