Data moved from databases to warehouses / data mart in 3 steps
1. Extract - data is extract from multiple databases
2. Transform - data is transformed in clean integrated standardized data
3. Load - data is loaded to a warehouse

# ETL process in practise

- Organizational data from Transaction Processing Systems are stored in operational / transactional databases
- ETL process is implemented and (some) data is transferred to the data warehouse
- The warehouse organizes the data by functional area, provider and product and makes it available for reports and analysis by business intelligence and advanced analysis tools
